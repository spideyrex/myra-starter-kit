### Added — Login appearance editor (v2.8 "Surface", bundle B)

- **Admin → System → Login appearance** (`/admin/appearance`): pick one of the four
  auth layouts from visual thumbnails, pick a background, upload a background
  image, and see a live light/dark preview. Gated by the existing `brand.view` /
  `brand.update` permissions — no new permission.
- **Live preview** resolves UNSAVED input on the server through the same path the
  save uses, so what the preview shows is what gets stored.
- **Background image upload** (`POST /admin/appearance/background/{surface}`):
  validated by magic bytes via `SafeImage`, SVG rejected twice, stored
  content-addressed on the **public** disk so an unauthenticated visitor can
  actually fetch it. A new `surface` cap raises the limit to 4 MB / 4096 px.
- **Contrast is advisory, never blocking.** The achieved WCAG ratio is shown and
  a warning is raised below `myra.brand.min_contrast`; the save always succeeds.
  A rule that can refuse an appearance can lock an admin out of fixing it.

### Security

- Every authored value is an allowlisted choice: layout key, background type,
  gradient/pattern recipe key and scrim. Colours must be six-digit hex.
- `*_bg_image_path` is **never** accepted from the update form — a path can only
  enter through the validated upload endpoint.
- Nothing is interpolated into a `style` attribute as raw CSS; the page binds a
  server-sanitised custom-property record, and there is no `v-html`.

### Notes for the merge

- `AppearanceWriter` writes the fourteen `appearance` rows **by name** through
  `DB::table('settings')`, never through bundle A's typed properties. `appearance`
  is already in `BrandManager::GROUPS`, so `forget()` plus the version probe is
  the whole invalidation story.
- `AuthPreviewSlot` delegates to `AppearanceManager::fromInput()` and
  `AuthLayoutRegistry::toClientSchema()` when those classes exist, and resolves
  locally otherwise. After the merge the delegation is the live path.
- Two tests (`AdminRoundTripTest::test_the_saved_appearance_reaches_the_login_page`,
  `AppearancePreviewTest::test_the_draft_layout_query_is_honoured_only_for_an_editor`)
  skip while the engine bundle is absent and become live at merge.
